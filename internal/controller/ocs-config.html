导入步骤（默认解析器）

  1. 点击上方「复制配置」按钮，复制完整 JSON。
  2. 打开 OCS 脚本设置 → 「题库设置」→ 找到「自定义题库解析器」，点击「新增」。
  3. 在编辑框中点击「读取剪贴板」，粘贴刚才复制的 JSON，确认列表出现 TikuAdapter 条目。
  4. 一路「保存」并启用该解析器，随便搜一道题验证；图片题的 images 处理器已包含，图片支持警告会消失。

提示：若浏览器剪贴板权限被拒绝，可手动全选上方 JSON 文本复制。url 使用当前页面地址（location.origin），换端口或域名后重新打开本页即可。
