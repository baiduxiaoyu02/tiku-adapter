# Feature Specification: 题库服务 v2 — GitHub 发布与模型供应商管理

**Feature Branch**: `001-v2-desktop-release`

**Created**: 2026-11-01

**Status**: Draft

**Input**: 用户描述："以后版本更新也直接用GitHub发布 顺便再升级一下题库管理界面 加上配置模型供应商的前端ui 像zcode一样"

## 用户场景与测试 *(mandatory)*

### User Story 1 - 面板配置模型供应商（Priority: P1）

用户在题库管理面板新增「模型供应商」配置页：可添加多个 AI 供应商（每个含名称、接口地址、API 密钥），为每个供应商配置普通模型与图片视觉模型，对任一供应商一键测试连通性，并将其中一个设为当前使用。所有更改保存后持久化，服务重启后仍然生效。

**Why this priority**: 这是软件作为"可分享产品"的核心能力——朋友拿到软件后无需手动编辑配置文件，在面板里填自己的 key 就能把 AI 增强跑起来。没有它，分享出去的软件只有半免费题库功能。

**Independent Test**: 打开管理面板 → 供应商页 → 添加一个供应商并填入有效 key → 点连接测试显示成功 → 将该供应商设为当前 → 搜题返回 AI 增强的答案。

**Acceptance Scenarios**:

1. **Given** 面板已登录，**When** 进入供应商页并点击「添加供应商」，**Then** 可填写名称/接口地址/密钥/模型/视觉模型并保存。
2. **Given** 已保存供应商，**When** 点击「连接测试」，**Then** 显示连通成功或明确的失败原因。
3. **Given** 存在多个供应商，**When** 将其中一个设为「当前使用」，**Then** 后续搜题的 AI 调用使用该供应商的配置。
4. **Given** 填入了错误的接口地址或密钥，**When** 保存或测试，**Then** 显示明确的错误提示而非静默失败。
5. **Given** 服务重启，**When** 再次打开面板，**Then** 之前保存的供应商配置仍然存在且当前选择不变。

### User Story 2 - 面板新建用户可直接登录（Priority: P1）

管理员在面板「用户列表」新建的用户（用户名+密码）能够立即用该用户名和密码登录面板。当前版本创建的用户无法登录（创建时密码丢失），此故事修复该缺陷。

**Why this priority**: 用户管理是面板的基础功能，建号不能登录等于多用户能力不存在。

**Independent Test**: 管理员创建用户 testuser/某密码 → 退出 → 用 testuser 登录成功。

**Acceptance Scenarios**:

1. **Given** 管理员已登录，**When** 在用户列表新建用户并设置密码，**Then** 该用户立即可以用该用户名和密码登录。
2. **Given** 新建的用户已登录，**When** 查看用户列表，**Then** 该用户存在且密码字段不对外泄露明文或哈希。

### User Story 3 - OCS 配置一键生成（Priority: P2)

用户打开 `http://<服务地址>/ocs-config` 即可看到为本服务地址自动生成的完整 OCS 题库配置（含图片题支持），一键复制后粘贴到 OCS 即完成对接。

**Why this priority**: OCS 对接是软件的核心使用方式；手工拼配置容易出错（历史踩坑：解析器模式、contentType、type 映射、转义），生成页消除全部踩坑点。

**Independent Test**: 浏览器打开 /ocs-config → 点复制 → 粘贴到 OCS → 保存刷新后搜题可用（含图片题 images 字段）。

**Acceptance Scenarios**:

1. **Given** 服务已启动，**When** 打开 /ocs-config，**Then** 显示完整配置 JSON（url 指向本机地址、含图片题 images 字段与正确的题型映射）。
2. **Given** 已复制配置并导入 OCS，**When** 在作业页搜题，**Then** 免费题库与 AI 均按配置工作且「图片题优化」警告不再出现。

### User Story 4 - GitHub Release 分发（Priority: P2）

软件维护者推送版本标签（如 v2.0.0）后，GitHub 自动构建并发布 Release，附上 Windows 安装包与单文件程序；朋友打开 Release 页即可下载安装，全程无需登录 GitHub 以外的任何账号，也无需手动编辑配置文件即可使用免费题库。

**Why this priority**: 这是"朋友直接能用"的分发通道——每次更新的交付成本从「发文件」降到「发链接」。

**Independent Test**: 推送一个版本标签 → GitHub Release 出现并附带安装包 → 下载安装 → 免费题库可用。

**Acceptance Scenarios**:

1. **Given** 源码已推送仓库，**When** 推送 v2.0.0 标签，**Then** GitHub 自动创建 Release 并附带 Windows 安装包与程序文件。
2. **Given** 朋友下载并安装，**When** 打开面板，**Then** 免费题库搜索可用，面板显示版本号。
3. **Given** 朋友想要 AI 增强，**When** 在面板供应商页填入自己的 AI 配置，**Then** AI 增强生效（与维护者使用的供应商互不影响）。

### User Story 5 - 配置安全（Priority: P2)

供应商密钥保存后不会在任何面板响应或开源仓库文件中明文泄露；仓库发布前历史中的敏感字符串已清除。

**Why this priority**: 公开发布后任何人都能翻提交历史，密钥泄露等于额度被人盗用。

**Independent Test**: 克隆公开仓库后全历史检索密钥字符串零命中；面板响应体检索零命中。

**Acceptance Scenarios**:

1. **Given** 软件已公开发布，**When** 克隆仓库并全历史检索 API 密钥字符串，**Then** 零命中。
2. **Given** 面板运行中，**When** 查看任何 API 响应体，**Then** 无明文密钥或完整哈希泄露。

## 需求（Functional Requirements）

- FR-1 面板支持模型供应商的增、删、改、查与「当前使用」切换；每个供应商含名称、接口地址、API 密钥、普通模型、图片视觉模型五个字段。
- FR-2 供应商配置支持连通性测试：向该供应商的模型发起一次真实请求并显示成功/失败与失败原因。
- FR-3 供应商配置持久化：保存后写入配置文件，服务重启后保留。
- FR-4 供应商配置变更后需一键重启服务生效，面板提供重启入口并在重启后自动恢复登录状态。
- FR-5 面板新建用户时密码必须入库（创建后可直接登录）；用户列表不得泄露密码哈希。
- FR-6 /ocs-config 页面按本机访问地址动态生成完整 OCS 配置（含图片题 images 字段），并提供复制按钮。
- FR-7 版本标签推送后自动构建 Windows 程序与安装包并发布 GitHub Release，Release 附使用说明。
- FR-8 公开源码仓库前，全部历史中的 API 密钥字符串必须清零（提交树与历史均不得含真 key）。
- FR-9 面板显示当前运行版本号。

## 成功标准（Success Criteria）

- 朋友从 GitHub Release 下载安装包到可搜题的全流程 ≤ 5 分钟（不含 AI key 注册）。
- 面板新增供应商到 AI 增强生效 ≤ 2 分钟（含连接测试与重启）。
- 公开仓库全历史密钥字符串检索零命中。
- 100% 的面板创建用户可成功登录。

## 关键实体

- **模型供应商（Provider）**：名称、接口地址、API 密钥、普通模型、图片视觉模型、是否当前使用。
- **用户（User）**：用户名、密码（哈希存储）、昵称、创建者。
- **OCS 配置（AnswererWrapper）**：名称、接口地址、请求方法与体、响应处理器、图片题字段。

## 非目标（Out of Scope）

- 不做 Docker 镜像发布（Windows 桌面版为分发重点；Docker 版本地保留可用）。
- 不做多语言界面（当前仅中文）。
- 不做移动端适配（面板面向桌面浏览器）。
- 不内置任何 AI 供应商密钥（朋友各自填写，维护者的密钥不进安装包）。
- 不做自动更新器（版本升级走 Release 页重新下载）。

## 澄清（Clarification）

- 「像 ZCode 一样」的落点 = 供应商增删改 + 密钥掩码显示 + 连通测试 + 当前使用切换 + 一键重启生效，不包含 ZCode 的全部能力（如模型市场、计费）。
- 图片题的视觉模型跟随供应商配置（每供应商可独立指定视觉模型，缺省回落普通模型）。
- GitHub 发布的安装包不内置任何 AI 密钥（朋友在面板自行填写）。

## 假设

- 朋友的 AI 增强由其各自填写的供应商 key 提供；维护者的 key 不进入安装包或公开仓库。
- 免费题库来源（第三方公共接口）对所有用户开箱可用，其可用性不由本软件保证。
- 公开发布前历史压缩为单个干净提交（用户已确认）。
